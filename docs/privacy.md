# Wallet APS: политика конфиденциальности / Privacy Policy

Последнее обновление / Last updated: 2026-11-03

## Русский

Wallet APS — офлайн-менеджер паролей и личных данных.

- Приложение не собирает, не передаёт и не продаёт ваши данные. У приложения
  нет учётных записей, серверов, аналитики и рекламы.
- Базы `.swl` хранятся только там, где вы их сохранили: на устройстве или в
  выбранном вами файловом хранилище (например, iCloud Drive). Содержимое баз
  зашифровано паролем, который приложение не сохраняет и не может восстановить.
- Доступ к фото или камере используется только когда вы сами прикрепляете
  изображение к карточке. Местоположение не используется.
- Версии для Windows, Android и Linux могут запрашивать у GitHub номер последней
  версии приложения; при этом никакие ваши данные не передаются. Версии для iOS и
  macOS обновляются через Apple и такой запрос не выполняют.
- Отзывы, отправленные через TestFlight, обрабатывает Apple по своей политике
  конфиденциальности; разработчик видит только то, что вы сами отправили.

## English

Wallet APS is an offline password and private data manager.

- The app does not collect, transmit or sell your data. It has no accounts,
  servers, analytics or advertising.
- `.swl` vaults are stored only where you save them: on your device or in a file
  provider you choose (for example, iCloud Drive). Vault contents are encrypted
  with a password that the app neither stores nor can recover.
- Photo library or camera access is used only when you attach an image to a card.
  Location is not used.
- The Windows, Android and Linux versions may ask GitHub for the latest app
  version number; none of your data is sent. The iOS and macOS versions are
  updated through Apple and do not make this request.
- Feedback sent through TestFlight is handled by Apple under its privacy policy;
  the developer sees only what you choose to send.
