# Wallet Sans

Linux font of Wallet APS, so text has the size and line height of the
Windows version (Segoe UI). Wallet Sans is Roboto (Apache License 2.0,
`LICENSE-Roboto.txt`, taken from the Flutter SDK material fonts) with the
vertical metrics of Segoe UI: ascender 2210, descender -514, line gap 0 of
2048 units, `USE_TYPO_METRICS` set. Glyphs are unchanged.

Weights: Regular 400, Medium 500 and 600 (Segoe UI Semibold is as wide as
Roboto Medium), Bold 700.
